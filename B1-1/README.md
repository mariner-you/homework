이 폴더는 B1-1 과제 제출물을 정리한 공간입니다.

- **1. LLM 모델 비교, 선정 보고서**: 과제 수행에 적합한 LLM을 비교하고 선정한 보고서

- **2-3. Few-shot 예시 및 검증 전략**: Few-shot 예시 구성과 검증 전략 정리
- **2-4. 환각 검증**: 생성 결과의 환각 여부를 점검한 문서
- **3. 10턴 이상의 대화 로그**: 실제 프롬프트 실험 및 대화 기록
